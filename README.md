# java-calculator-precourse
# 문자열 덧셈 계산기

## 기능 구현 목록

---

### 입력
- [x] "덧셈할 문자열을 입력해 주세요." 를 출력 후 String(구분자와 양수로 구성된 문자열)을 받는다.

### 커스텀 구분자 등록
- [x] 커스텀 구분자 입력구조(// \n)로 커스텀 구분자 등록한다.
  - 예외
    - [x] 커스텀 구분자 입력구조(// \n)가 틀릴 경우.
    - [x] 커스텀 구분자로 "."이 입력 됐을 경우. (소수계산에 문제가 됨)
    - [x] 커스텀 구분자로 숫자들어올 경우.

### 구분자로 분리
- [x] 기본 구분자(, or :)와 커스텀 구분자로 입력값을 구분한다.
  

### 계산 기능
- [x] 구분된 숫자들을 합한다.
  - [x] 소수가 포함된 계산
  - [x] 정수끼리의 계산
  - 예외
    - [x] 양수가 아닌 경우
      - [x] 0인 경우
      - [x] 음수인 경우
### 출력
- [x] "결과 : ?"형태로 계산된 값 출력
- [x] 정수끼리의 계산은 정수로 출력
- [x] 소수가 포함된 계산은 수소로 출력
